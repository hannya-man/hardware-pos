# Reporting a security problem

If you find a weakness in the RRC Merchandise POS, please report it
privately rather than in a public issue: use **Report a vulnerability** on
this repository's **Security** tab. Include what you found and how to see it
happen. Please don't test against the store's live system or its data.

The store's owners review reports and aim to answer within a week. How the
system protects data is described in
[docs/compliance](docs/compliance/README.md).
